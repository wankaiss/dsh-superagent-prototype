Every import from `../src` is `import type`, except the filter arrays in `src/app/api.ts` (that file has only type imports). Build check: `panel/dist` contains neither `node:` nor `@deepseek-ai`.

- **G6 corrected:** idea 14 only partially (Session view = link out to the DSH UI on :3082; `openSession` is DSH-only). Settings/prompt editing is an explicit out-of-scope entry with its reason.
